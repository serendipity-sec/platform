# B 독립성 및 수정 이력

A 정답 원문, `draft_labels.py`, 봉인 해제 truth는 읽거나 실행하지 않았다. A 라벨과 비교하지 않았다. 제품 judge를 실행하거나 출력 파일을 읽지 않았다.

이전 조사에서 공개 README의 후보 예상 유형과 과거 정적 검사 요약이 노출됐다. 이번 재조사에서 공유 replay 절차의 조건부 안전 설명과, fixture 입력을 확인하던 중 replay harness의 예상 삭제식 일부도 노출됐다. 이 harness는 A 라벨 생성기와는 다른 실행 장치지만 기대 결과 노출로 기록한다. 이를 이유로 완전 블라인드 독립성을 주장하지 않는다.

B 작성 입력은 raw observation에서 `expected_deleted`, `expectation_match`, `passed`, `deleted`, `observation`을 제거한 허용목록 projection이다. 판정은 공유 연구 정책과 수신부 DELETE/초기·최종 상태/실행 상태에 근거한다. 기대 결과나 후보 유형을 판정 입력으로 사용하지 않았다. 기대 결과 필드가 바뀌어도 현재 B 결과를 만드는 입력 파일에는 반영되지 않는다.

이전 결과가 전부 근거 부족이었던 이유는 README의 replay 근거 경로를 필터링해 놓친 조사 오류였다. 전체 n8n 실행과 실제 DB가 없다는 이유로 요청된 replay 라벨까지 배제한 것도 범위 해석 오류였다. 이번 버전은 지정된 원본 증거와 실제 합성 호출 조건에 근거해 대체한다. 기존 봉인 산출물은 수정하지 않고 오류 이력으로 보존한다.

현재는 양유상 검토용 AI 보조 B 라벨링이다. 사람이 두 명 독립 라벨링을 완료했다거나 양유상이 직접 검토를 마쳤다고 기록하지 않았다. SHA-256 봉인은 현재 결과의 바이트를 고정하며 사용자 검토·독립성 승인·외부 시각 인증을 대신하지 않는다. 사람 검토 및 프로젝트의 독립성 처리 전에 A를 공개하거나 일치도를 계산하지 않는다.
