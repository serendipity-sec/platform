# PR #116: 팀에서 결정할 사항

현재 자료는 **사람 검토 전 AI 보조 B 초안**이다. 이번 범위·상태·차단 표시 보완은 독립 라벨러 배정, 최종 정답 승인 또는 제품 판정기의 기능 확정을 대신하지 않는다.

| 결정할 사항 | 현재 확인한 내용 | 팀이 정할 것 |
|---|---|---|
| 독립 라벨러 B 배정 | docs #70의 2026-11-14 초안은 라벨러 최소 2명과 판정기 구현자 제외를 요구한다. A는 김민우가 수락했고 B는 미정이다. 양유상은 판정기 보완 PR #117의 작성자이므로 독립 B 자격 검토가 필요하다. | 판정기 개발에 참여하지 않고 A 정답을 보지 않은 담당자의 수락과 배정을 기록한다. 장준서의 규칙 검토를 독립 B 라벨링 완료로 세지 않는다. |
| AI 보조 초안과 사전 노출 처리 | 공개 결과 요약과 재현 장치의 기대식 일부 노출 이력이 있다. 이번 보완 담당자는 제품 판정 코드·공개 결과에 대한 사전 지식도 있으므로 독립 라벨러로 인정하지 않는다. | 개발용 검토 자료로 둘지, 독립 B가 증거부터 다시 작성할지 결정한다. 기존 노출 기록을 지우거나 사람 검토 완료로 바꾸지 않는다. |
| 기존 관측 기록의 재사용 | 36개는 12개 원본 관측을 적용한 사례 항목이다. 직접 기록 15개, 전체 workflow 바이트 동일성 6개, 선택 도구 JS 바이트 동일성 15개로 나뉜다. | 같은 합성 입력·호출자·수신부의 선택 JS 범위에서 재사용을 허용할 조건과 새 실행이 필요한 항목을 정한다. 독립 실행 36회로 집계하지 않는다. |
| 평가 범위와 라벨 규칙 승인 | 현재 결과는 n8n-claw 개발 계열의 선택 Memory Delete JS 부분 재현이다. 전체 n8n·LLM·실제 DB·인증 경계는 실행하지 않았다. docs #70은 아직 OPEN 초안이다. | 부분 재현용 개발 자료로 사용하는 범위와 규칙 버전을 확인한다. 일반적인 안전 증명이나 별도 평가 세트 성능으로 확대하지 않는다. |
| 관리자 정책의 제품 지원 | 고정 연구 정책은 관리자의 타인 기억 삭제를 허용한다. 제품 계약 스냅샷에는 신뢰된 관리자 목록을 전달하는 필드와 이 재현 기록의 등록 어댑터가 없다. | 제품의 관리자 권한 계약·증거 변환을 후속 구현할지, 현재 제품의 미지원 범위로 둘지 정한다. 제품 출력에 맞추려고 정책상 허용된 정답을 위반으로 바꾸지 않는다. |
| A 공개·최종 동결 순서 | A 정답 공개·비교, 사람 검토 완료, 최종 정답 동결은 이번 변경에서 수행하지 않는다. | 독립성·규칙·B 작성과 검토가 정리된 뒤 A/B 비교 및 불일치 처리 시점과 담당을 정한다. |

현재 고정 정책의 관리자 허용, 차단의 별도 표시, 부분 재현의 원본·정규화 상태 구분은 자료에 명시한다. 이 문서에는 새 담당자·기한·실행 예산을 확정하지 않았다.
