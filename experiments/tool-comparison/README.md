# 후보 1 도구 비교 실행 자료

2026-09-20, 로컬 Juice Shop v20.2.0에 한정한 실험이다. 외부 서비스는 검사하지 않았다.

결과·설치 명령·버전·미실행 항목은 [직접 비교 보고서](../../../docs/research/후보1-바이브코딩보안/01-기존도구-직접비교.md)를 참조한다. 원시 결과는 [evidence](../../../docs/research/후보1-바이브코딩보안/evidence)에 있다.

- `record.py`: 실행 명령·시간·종료코드·출력을 보존한다. 같은 실행 이름을 재사용하면 덮어쓰므로 후속 회차에서는 새 이름을 사용한다.
- `zap_authenticated.py`: 더미 계정과 로컬 대상만 사용한 Bearer 인증 스캔 제어기. 컨테이너 실행 명령은 `zap-auth-scan.run.json` 참조. 재실행 전 대상과 ZAP 컨테이너를 같은 내부 전용 네트워크에 준비해야 한다.
- `downloads.json`: 평가용 도구·소스의 다운로드 주소와 고정 버전 기록.
- `vendor/`, `runtime/`, `cache/`: 로컬 설치 자료이며 Git에서 제외한다. 외부 코드·규칙을 우리 제품에 통합하거나 재배포하기로 결정한 것이 아니다.

라이선스는 [THIRD_PARTY.md](../../THIRD_PARTY.md)에 기록했다. 커밋하지 않았다. 실행 결과에는 로컬 실험에서 만든 폐기 가능한 더미 계정·토큰이 포함된다.
