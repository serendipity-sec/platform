# platform

**AI 워크플로 구성요소의 공급망 보안 검사 및 공유 플랫폼** — 구현 저장소

외부에서 가져온 규칙 파일·스킬·MCP 서버·플러그인을 사용 전에 정적으로 검사하고,
구성요소 사이의 연결과 위험 근거를 그래프로 보여 주며, 검사한 버전과 검토 이력을 팀이 함께 재사용하도록 합니다.

> 문서(회의록·계획서·보고서)는 [`docs`](../docs) 저장소에 있습니다.

## 이번 학기 범위

**필수**

| # | 기능 | 완료 기준 |
|---|---|---|
| ① | 규칙 파일 검사 (`AGENTS.md`, `CLAUDE.md`, `.cursor/rules/*.mdc`) | 파일·행 번호와 근거가 있는 한국어 검사 보고서 |
| ② | 스킬 검사 (`SKILL.md` + 동봉 `scripts/`, `references/`) | 지침과 동봉 파일을 연결한 결과 + 미지원 파일 목록 |
| ③ | 워크플로/위험 경로 시각화 | 확인된 연결(실선)과 추정 연결(점선) 구분, 노드 선택 시 원본 근거 표시 |
| ④ | MCP 서버·플러그인 검사 | 접근 자원 목록 + 선언·구현 불일치 후보 |
| ⑤ | 보안상 변경 비교와 팀 공유 | 새 파일 접근·외부 연결·실행 요청 식별, 출처·해시·검토 기록 저장 |

**이번 학기에 하지 않는 것**

- MCP 서버를 임의로 실행하거나 외부 플러그인을 설치하지 않습니다. 제출된 자료만 정적으로 검사합니다.
- 스크립트 분석은 Python·JavaScript/TypeScript의 제한된 패턴부터 시작합니다. 전 언어·바이너리·동적 동작 분석은 범위 밖입니다.
- SBOM, 배포 서명 검증, 실시간 실행 차단, 공개 마켓 운영은 후속 학기 과제입니다.

**검사 결과는 "안전 인증"이 아닙니다.** 지원 범위와 검사 근거를 공개하는 검토 지원 도구이며,
결과 상태는 `검사 완료 / 주의 사항 있음 / 검토 대기 / 검사 불가 / 재검사 필요`로 표현합니다.
